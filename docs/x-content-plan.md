# X 内容管线：一条技能 = 一条帖子

这个技能库同时是 X（推特）账号的内容弹药库。目标人设"用 AI 搞钱的独立开发者"，每条技能天然就是一篇帖子的骨架。

## 改写公式（短推版）

```
痛点（一句话开场，扎心）
↓
"三步让 Muse 替你干："
1/ ...
2/ ...
3/ ...
↓
实话：（有则加，没有不加，显得真诚）
```

## 改写公式（thread 版，一周 1-2 篇）

1/ 开头：痛点 + "我试了一套三句话的用法"
2-4/ 三步，每条展开讲一次真实使用场景
5/ 实话：哪步 Muse 搞不定、我怎么绕过去的
6/ 结尾：完整版 500 条在 GitHub（挂仓库链接）

## 选稿优先级

1. 搞钱与副业、金融与投资、独立开发三个分类优先（对人设）
2. 标了 `top10: true` 的先发（已经筛过一轮传播力）
3. "实话实说"分类适合做观点帖（AI 的边界，天然带讨论度）

## 节奏建议

- 每条技能只发一次，避免重复
- 发完把帖子链接记回对应技能文件底部的 `x_post:` 字段（可选），方便以后复盘哪类选题数据好
- 数据好的选题扩展成 thread，数据差的分类以后少写

500 条 ≈ 一年半的日更弹药，配合热点评论区互动做冷启动。
