**痛点**：一个人开发节奏全凭感觉，一周过去不知道自己到底推进了多少。

**三步做法**：
1. 每周日把这周的 commit 和待办发给 Muse：「总结成周报：完成了什么、卡在哪、下周干什么」。
2. 让它算笔账，「这周有效编码几天，被杂事吃了几天」。
3. 攒够四周让它复盘，「我这一个月的节奏是变快了还是在原地打转」。

**实话**：第 1 步每周的 commit 得你亲手发；它只负责总结复盘，下周干什么还是你说了算。
