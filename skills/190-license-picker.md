**痛点**：MIT、Apache、GPL 看得头大，选错了以后改都改不掉。

**三步做法**：
1. 跟 Muse 说你的情况：「个人开源项目，想让大家随便用，但怕大公司拿去闭源商用」。
2. 让它对比 MIT、Apache-2.0、GPL，「表格列：商用限制、改代码要不要开源、专利授权」。
3. 选定后让它生成 LICENSE 全文和 README 里的一句话声明，你复制进仓库。

**实话**：它不是律师，选定前你自己去官网核对一眼原文，别只听它说。
