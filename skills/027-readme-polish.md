**痛点**：README 写得像说明书，访客三秒划走，star 全是误点的。

**三步做法**：
1. 把 README 发给 Muse：「以第一次点进来的开发者视角重写，第一屏讲清这项目解决什么问题」。
2. 让它补上 30 秒快速上手，「复制粘贴就能跑起来的那种」。
3. 最后让它挑刺，「删掉三句正确的废话，告诉我访客看到第几行会关掉页面」。

**实话**：三步它都能自己干，你只管复制粘贴；但项目本身值不值得留人还得看你的代码，它写不出好项目。
